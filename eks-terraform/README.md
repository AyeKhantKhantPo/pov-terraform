# EKS Cluster Deployment with Terraform (eksctl-inspired)

This repository contains Terraform code to provision an Amazon EKS cluster from scratch. The infrastructure design, routing, and security group rules are directly inspired by the CloudFormation templates generated by `eksctl`, providing a robust, production-ready network topology.

## 🏗️ Architecture & Features

- **EKS Cluster**: Version `1.33` (Customizable via variables).
- **VPC Topology**: Dedicated VPC (`192.168.0.0/16`) spanning 3 Availability Zones in `ap-southeast-1`.
- **Subnets**: 3 Public subnets (for ALBs/IGW) and 3 Private subnets (for internal resources and EKS nodes).
- **Routing**: Single NAT Gateway configured in the public subnet for private node internet access.
- **Compute**: EKS Managed Node Group utilizing an EC2 Launch Template with modern `gp3` EBS volumes and IMDSv2 enforced.
- **Security**: Granular Security Groups separating Control Plane and Worker Node traffic, mimicking `eksctl` best practices.

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- [Terraform](https://developer.hashicorp.com/terraform/downloads) (v1.4.0+)
- [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) (Configured with the `master-eks-admin` profile)
- [kubectl](https://kubernetes.io/docs/tasks/tools/)

## 🚀 Quick Start

**1. Clone and configure**  
Ensure your `terraform.tfvars` file is configured with your desired region, profile, and cluster name.

**2. Initialize Terraform**  
Downloads the AWS provider and initializes the working directory.
```bash
terraform init
```
**3. Preview Infrastructure Changes**
Review the resources Terraform plans to create.
```bash
terraform plan
```
**4. Deploy**
Provision the infrastructure in your AWS account (takes ~15-20 minutes).

```bash
terraform apply --auto-approve
```
## 🔌 Connect to the Cluster
Once the deployment is complete, update your local kubeconfig to interact with the cluster:
```bash
aws eks update-kubeconfig \
  --region ap-southeast-1 \
  --name akkp-eks-sgp-cluster \
  --profile master-eks-admin
```

Verify your worker nodes are up and running:
```bash
kubectl get nodes
```
## 🧹 Cleanup
To avoid incurring future AWS charges, destroy the infrastructure when you are done:
```bash
terraform destroy --auto-approve
```
